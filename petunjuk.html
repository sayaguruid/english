📖 Petunjuk Pengelolaan & Upload

Situs statis ini bisa diunggah ke GitHub Pages atau hosting apa pun tanpa database dan tanpa build.

1. File mana yang perlu disentuh?

FileStatusKapan disentuh
index.html🔒 INTITidak perlu — beranda & pencarian pelajaran otomatis
style.css🔒 INTITidak perlu — hanya kalau mau ganti tampilan

✅ Prinsipnya: menambah pelajaran = menambah 1 file baru saja. File inti tidak pernah berubah, jadi tidak ada risiko merusak aplikasi.

2. Menambah pelajaran baru (5 langkah)

  1. Salin template-pelajaran.html menjadi pelajaran3.html (lanjutkan nomor berurutan dari pelajaran terakhir yang ada).
  2. Ganti judul di bagian <title> atas file.
  3. Edit blok JSON di dalam <script id="lesson-data">: kategori, judul, vocab, quiz, dialog, homework. Ada komentar penjelasan lengkap di dalam template.
  4. Hapus baris "comingSoon": true jika pelajaran sudah siap dimainkan (biarkan jika ingin tampil terkunci 🔒).
  5. Uji: buka pelajaran3.html di Chrome, mainkan sampai selesai. Setelah itu beranda akan menampilkannya secara otomatis (refresh dengan Ctrl/Cmd+Shift+R).
⚠️ Aturan penting: nomor file harus berurutan tanpa loncat (1, 2, 3, ...). Beranda berhenti mencari di nomor pertama yang tidak ada. Batas pemindaian saat ini 60 pelajaran. JSON tidak boleh ada komentar, koma ganda, atau koma di item terakhir.

3. Cara kerja otomatis (tidak perlu diatur)

  • Penomoran: nomor tampil di beranda = nomor file (pelajaran4.html → "Pelajaran 4").
  • Buka-kunci: pelajaran N terbuka setelah pelajaran N−1 selesai; pelajaran 1 selalu terbuka; comingSoon selalu terkunci. Progres tersimpan per browser/domain — jika pelajaran terasa "terkunci padahal sudah selesai", itu karena berpindah browser, HP, atau domain. Di layar kunci ada tombol 🔓 Buka Tetap (Orang Tua) untuk membuka pelajaran tanpa menyelesaikan sebelumnya (cukup ditekan sekali, tersimpan).
  • Kategori: kategori diambil dari data pelajaran; urutan kategori mengikuti pelajaran yang muncul duluan. Pelajaran dalam satu kategori harus menulis category yang sama persis (id, nama, emoji, warna).
  • Bagian opsional: di dalam data boleh ditambahkan "warmup" (dialog pemanasan/ulang pelajaran sebelumnya), "game" (permainan Find It! — anak menyentuh gambar sesuai perintah), dan "speakingTest" (kalimat Tes Bicara; jika tidak ada, diambil otomatis dari baris anak pada dialog). Vocab juga bisa memakai "gestureLabel" untuk mengganti label "Gerakan" (mis. "Suara" untuk kosakata bunyi hewan — lihat pelajaran4.html). Nomor "Bagian N" dan progres menyesuaikan otomatis; contohnya lihat pelajaran2.html, pelajaran3.html, pelajaran4.html dan template-pelajaran.html.
  • Profil nama anak: di beranda anak/orang tua menuliskan nama (bisa beberapa nama — tinggal pilih lewat chip 🧒 di pojok kanan atas). Nama dipakai untuk sapaan “My name is ...” dan kalimat pujian; tanda “...” di kalimat pelajaran otomatis diganti nama yang dipilih. Data profil tersimpan di perangkat.
  • Suara benar/salah: jawaban benar di kuis/permainan/cek pengucapan berbunyi “ding ✨”, jawaban salah berbunyi “buzz” — jadi anak langsung tahu hasilnya tanpa harus membaca.
  • Tes Bicara: setelah dialog ada bagian 🎤 tes ucap: kalimat muncul → anak dengar 🔊 → tekan 🎤 dan ucapkan. Kalau sudah benar, tombol LANJUT menyala menuju kalimat berikutnya; kalau belum, ada “🔄 Ucap Ulang” dan “Lewati”. Bagian ini otomatis muncul di semua pelajaran (jika browser mendukung mikrofon).
  • Progres & bintang: tersimpan di browser perangkat (localStorage) — aman di GitHub Pages maupun hosting (satu domain = satu progres).
  • Hadiah: daftar bintang per pelajaran & lencana terisi otomatis.

4. Upload ke GitHub Pages

  1. Buat akun di github.com (gratis), lalu klik New repository — nama bebas, misal kids-english, pilih Public.
  2. Di halaman repo, klik uploading an existing file (atau Add file → Upload files).
  3. Seret semua file dari folder ini: index.html, style.css, app.js, pelajaran1.html, pelajaran2.html (+ pelajaran lain & template bila mau). Klik Commit changes.
  4. Buka tab Settings → Pages (menu kiri). Pada Build and deployment, pilih Source: Deploy from a branch, Branch: main dan folder / (root), lalu Save.
  5. Tunggu 1–2 menit, muat ulang halaman itu — akan muncul alamat seperti https://username.github.io/kids-english/.
  6. Buka alamat itu di HP — beranda otomatis menemukan semua pelajaran. Selesai! 🎉
💡 Nanti setiap menambah pelajaran: upload file pelajaranN.html baru ke repo yang sama (Add file → Upload files → Commit). File inti tidak perlu diunggah ulang.

5. Upload ke hosting sendiri (cPanel/dll)

  1. Masuk ke File Manager / FTP hosting Anda.
  2. Masuk ke folder public_html (atau subfolder, misal public_html/english).
  3. Unggah semua file di folder ini (bisa di-zip dulu lalu Extract di server).
  4. Buka https://domainanda.com/ (atau /english/) — langsung jalan, tanpa setting apa pun.

6. Menguji di komputer sebelum upload

Beranda butuh server web agar bisa mencari file pelajaran (jika dibuka lewat klik ganda/file://, pencarian diblokir browser). Dua cara mudah:

  • Via GitHub/hosting dulu — cara paling praktis: upload, lalu uji langsung online.
  • Server lokal (jika ada Python): di folder ini jalankan python -m http.server 8000, buka http://localhost:8000.

Jika tetap dibuka lewat file://, beranda menampilkan kolom "Nomor pelajaran" untuk membuka pelajaran langsung, dan file pelajaranN.html tetap bisa dibuka langsung & berfungsi penuh.

7. Pasang di HP seperti aplikasi

Situs ini sudah berbentuk PWA (manifest, ikon, layar berdiri sendiri). Setelah diunggah (HTTPS), anak bisa memakainya seperti aplikasi:

  • Android (Chrome): buka alamatnya → menu ⋮ → Tambahkan ke layar utama → muncul ikon 🦖 sendiri, terbuka tanpa address bar.
  • iPhone (Safari): buka alamatnya → tombol Bagikan → Tambahkan ke Layar Utama.
  • Saat online pertama kali, halaman tersimpan otomatis (service worker) sehingga tetap bisa dibuka saat sinyal lemah.

8. Fitur & catatan

  • 🔊 TTS suara guru perempuan, normal & lambat — pakai suara bawaan browser (butuh internet untuk font, suara tetap jalan offline).
  • 🔔 Efek suara benar = “ding”, salah = “buzz” — memakai Web Audio, dengan cadangan file sfx/*.wav jika audio diblokir browser.
  • 🎤 Mikrofon cek pengucapan memakai Web Speech API — paling akurat di Chrome/Edge; saat di GitHub Pages (HTTPS) akan diminta izin mikrofon sekali.
  • 💾 Reset progres untuk mulai ulang: buka aplikasi, tekan F12 → tab Console → ketik localStorage.clear() → muat ulang.
  • 🔓 Akses langsung pelajaran berikutnya bisa diakses lewat tombol hijau di layar hasil — tetap berurutan karena dicek lewat progres.
